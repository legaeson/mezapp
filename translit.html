Лезгинский транслитератор (Латиница)

Практическая система: гъ → ġ, хь → xh, гӀ → g', хӀ → x', ы → ɨ, ч → c, ж → j

Справка по действующим правилам
  • Увулярные / Диграфы: гъ → ġ, гь → h, гӀ → g', хь → xh, хъ → qh, хӀ → x', къ → q, кь → q'
  • Абруптивы: пӀ → p', тӀ → t', кӀ → k', цӀ → ts', чӀ → c'
  • Лабиализация: гъв → ġw, хьв → xhw, хъв → qhw, кӀв → k'w, цӀв → ts'w, чӀв → c'w и т.д.
  • Гласные: ы → ɨ, аа → ā, аьаь (--mazin) → ǣ, ъ → ', ь → (удаляется вне диграфов)
  • Мазинские кольца: чӀ˚в → c'˚w, чh˚ → ch̊, ж˚в → j̊w, ш˚ → sh̊ и т.д.
