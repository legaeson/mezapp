Лезгинский транслитератор (Латиница)

Практическая система: ч → ch, чӀ → ch', ц → c, цӀ → c', в → w, уь → y, ж → zh, дж → dzh, я → ja / æ

Справка по действующим правилам
  • Абруптивы: чӀ → ch', цӀ → c', кӀ → k', тӀ → t', пӀ → p', кь → q'
  • Шипящие и аффрикаты: ч → ch, ш → sh, ж → zh, дж → dzh, дз → dz, ц → c, щ → shch
  • Увулярные и гортанные: къ → q, хъ → qh, гъ → gh, гь → h, хӀ → h, хь → h, х → x
  • Гласные: уь → y, я → ja (в начале слова / после гласных) и æ (после согласных), аь → æ, оь → œ, ы → ə, ю → ju, ё → jo
  • Буква «Й»: всегда → j
  • Согласная «В» и знаки: в → w; знаки ъ, ь и одиночная палочка Ӏ удаляются
